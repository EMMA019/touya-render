# Dating-sim growth (親密度)

燈夜の成長は、会話回数で上がる **キャラごと** の親密度です。日付シムらしい距離感を保ち、親密な話は「仲良くなったあと」だけ開きます。

閾値の正本は `shared/affinity.json` です。

| 段階 | 名前 | 通数 |
| --- | --- | --- |
| 0 | 知り合い | 0 |
| 1 | 仲良し | 10 |
| 2 | 特別 | 30 |
| 3 | 絆 | 60 |

## NSFW ゲート（特別）

intimate / NSFW は **年齢確認だけでは足りません。** そのキャラの親密度が **特別（level ≥ 2）** になってから、年齢確認済みなら開けます。

- 仲良し（約10通）ではまだ早い。特別（約30通）がデートシムの「距離が縮まった」ラインです。
- ゲートは **キャラ単位**。一人と特別でも、他の子は知り合いのままです。
- `TOUYA_DEBUG_UNLIMITED` は日次通数だけです。親密度も NSFW も通しません。
- 判定の正本は `canAccessNsfw({ affinityLevel, ageConfirmed })`（`src/lib/chat-mode.ts`）。クライアントは表示用、サーバーが強制します。

特別になる前:

- その子のチャットを NSFW に切り替えられない（`POST /api/mode` と `POST /api/chat` が拒否）。
- UI はトグルをロックし、「もっと仲良くなったら」「特別になってから」と出す。
- `nsfwOnly` の場面は、万一 NSFW モードでも閉じたまま。タイトルは出さず、ロック用の hint だけ出します。

特別のあと + 18歳確認:

- 今までの SFW / NSFW 二重モードと、`nsfwOnly` 場面がそのまま使えます。

## レベルアップ

消費されたユーザー送信で親密度が上がり、段階が変わると API が `leveledUp` と `levelUpMessage`（例: 「特別になった」）を返します。Web / Android はバナーで出します。
