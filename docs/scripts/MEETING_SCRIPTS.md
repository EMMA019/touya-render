# 燈夜（Touya）出会い台本 設計総論（MEETING_SCRIPTS）

## 1. 出会いのゲーム的意味

『燈夜（Touya）』における「出会い（Encounter）」は、プレイヤーとヒロインが初めて交差する特別なプロローグです。

### 1.1 目的と役割
- **関係性の起点（Level 0: 知り合い確定）**:
  - 本作の親和度は「知り合い（Lv 0 / at: 0）→ 仲良し（Lv 1 / at: 10）→ 特別（Lv 2 / at: 30）→ 絆（Lv 3 / at: 60）」で進行します。
  - 出会い台本を完走することで、ヒロインとの関係が正式に「知り合い」として確定し、ホーム画面や日常対話ループへ合流します。
- **初回対話ハードルの解消**:
  - 白紙の自由入力から始めるのではなく、ラブプラス風の選択肢式導入シナリオ（3〜5往復）を提供することで、プレイヤーに世界観・シチュエーション・キャラの距離感を自然に浸透させます。
- **日常シチュエーションの解放トリガー**:
  - 出会いクリアによって各キャラの基盤となる日常シチュエーション（ひより: 雨のカフェ、凛音: 終業後オフィス、白石: 夜の屋上、クララ: 黄昏テラス）がアンロックされます。

---

## 2. 初回強制フロー（First Encounter Flow）

### 2.1 シーケンス
1. **ヒロイン選択 / 初回起動**:
   - プレイヤーがヒロインを初めて選択した際、自由チャット入力欄はロックされ、専用の「出会い台本」シーケンスが自動起動します。
2. **導入対話（3〜5往復）**:
   - 各ステップでヒロインの発話（2〜4文の短文、口調完全一致）の後、プレイヤーに2〜3個の選択肢が提示されます。
3. **クリア判定 & フラグ付与**:
   - 最終ノード到達で「出会い完了フラグ」および「日常シチュ解放フラグ」が保存されます。
4. **日常ループへの移行**:
   - 確定後、自由チャットモードへシームレスに遷移。以後、出会いでの選択や記憶を踏まえた日常の会話が可能になります。
   - ※回想モード等でいつでも再読可能（フラグや親和度を巻き戻さずに閲覧できる設計を推奨）。

---

## 3. 選択肢と分岐のルール

### 3.1 分岐設計の原則
- **バッドエンドなし**:
  - 不正解を選んで即終了・好感度激減などのペナルティは存在しません。プレイヤーの好むスタンスで対話を楽しめます。
- **トーン分岐（態度・雰囲気のバリエーション）**:
  - 各選択肢は「素直 / 好意的」「控えめ / 観察」「少し軽口 / 戸惑い」といったトーンの違いを持ち、ヒロインの反応台詞が1往復程度変化したのち、自然に共通フローへ合流します。
- **冷たさは軽く**:
  - ツンやクールなキャラであっても、出会い時点で過度な拒絶はせず、「警戒しつつも立ち去らせない」「距離を測りながら付き合う」塩梅を厳守します。

### 3.2 ノード仕様（データ定義フォーマット）

各シナリオファイルは、プログラム実装（JSON / TypeScript / YAML）へ直接落とし込めるよう、以下の規格で記述します。

```yaml
id: <node_id>             # 例: meet_01, meet_02a
speaker: <character_id>   # hiyori | rione | shiraishi | clara | player
text: |                   # 2〜4文。キャラ口調厳守
  セリフ本文
choices:                  # プレイヤーの選択肢（2〜3択）
  - id: choice_a
    text: "選択肢テキスト"
    tone: "素直 / 共感"
    next_id: meet_02a
  - id: choice_b
    text: "選択肢テキスト"
    tone: "遠慮 / 控えめ"
    next_id: meet_02b
flags_set:                # クリア時やノード通過時に付与されるフラグ
  - flag_name
```

## 4. 知り合うビート（B1〜B3）と告白手前フックの設計

「知り合い（Lv 0）」から「仲良し（Lv 1 / 親和度 10）」、「特別（Lv 2 / 親和度 30）」への進展をドラマチックにするため、出会い台本と合わせて以下のマイルストーンを定義します。

| ビート / フック | 親和度目安 | テーマ | 意味・役割 |
|---|---|---|---|
| **出会い（クリア）** | Lv 0 (at: 0) | 接点と認識 | 顔と名前を認識し、その場所に通う理由ができる |
| **B1: 名前の確定・呼び方** | Lv 0 (at: 2〜3) | 互いの名乗り | 単なる客/同僚/通りすがりから、個人の名で呼び合う関係へ |
| **B2: 好み・癖の共有** | Lv 0 (at: 5〜7) | 私的な一面 | 好きな飲み物、習慣、弱点など「他人に言わない一面」を共有 |
| **B3: 再訪の約束・定着** | Lv 0 (at: 9) | 「また来る」の確信 | 偶然ではなく「あなたがいるから来る」への変化（仲良し昇格直前） |
| **告白手前フック** | Lv 1 (at: 28〜29) | 境界線の揺らぎ | 友人関係の枠を超え、互いに異性として意識する決定的な夜 |

## 5. 作品前提・倫理ガイドライン

1. **成人キャラ・年齢数字なし**:
   - 全ヒロインは大人の女性（大学生・秘書・研究者・実業家）。台詞やテキストに具体的な年齢数字（20歳、24歳等）は一切出しません。
2. **制服シチュエーション・学生萌えフレーミングの禁止**:
   - 大学生設定（ひより）や他キャラにおいても、セーラー服・ブレザー等の学校制服、未成年を想起させる演出・シチュエーションは完全禁止です。
3. **NSFWの除外**:
   - 出会い〜知り合いフェーズには性的な描写や過度な露出は含めません（「特別」以降の別設計）。
4. **文量の最適化**:
   - 長文ノベルではなく、1ターン2〜4文のテンポの良いチャットSLG台本として構成します。
